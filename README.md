# Neon Rift 3D

Готовая браузерная 3D-игра без внешних библиотек и без установки движка.

## Как запустить

1. Распакуй архив.
2. Открой `index.html` в Chrome, Edge, Firefox или Safari.
3. Нажми **Играть**.

## Управление

- `WASD` или стрелки — управление кораблём
- `Space` — выстрел
- `P` — пауза
- `R` — рестарт

## Что внутри

- Самописный WebGL-рендерер
- 3D-корабль, препятствия, дроны, кристаллы, выстрелы
- Очки, щит, ускорение сложности
- Звуки через Web Audio API
- Полностью офлайн-проект: HTML + CSS + JavaScript

## Файлы

- `index.html` — точка входа
- `style.css` — интерфейс
- `src/game.js` — вся логика игры и 3D-движок
